Make an employer list

Type or paste companies — one per line — and JobAssist turns them into the employer-tracking spreadsheet (same layout as the original: groups, stars, status, contacts and a summary tab). Free: no Claude is used.

How to write the list
  • A line ending with : starts a group, e.g. London tech: — the companies below it go in that group.
  • Put Y (or *) after a company to star it: Monzo, Y
  • Optional: a careers page link after the name: Wise, https://wise.jobs. Or the group on the same line: Accenture, Consulting
  • Lines starting with # are ignored. Copying two columns from a spreadsheet works too.
  • Optional first lines: University: Leeds (names the alumni column) and CV versions: Data, Software (a dropdown).
